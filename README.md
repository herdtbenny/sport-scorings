# Sport Scorings

Live-Tabellen, Spieltage und Torjäger für Bundesliga, Premier League und mehr – direkt aus der OpenLigaDB.

Teil meines Portfolios: [portfolio.websbybenny.de](https://portfolio.websbybenny.de/#projects)

## Funktionen

- Tabelle, Spieltage, Torjäger und Teamsuche
- Bundesliga 1–3, DFB-Pokal, Champions League, Premier League, Primera División, Serie A sowie WM und EM
- Wettbewerb und Saison frei wählbar, Spieltag-Navigation
- Daten live aus der öffentlichen REST-API der OpenLigaDB, ohne eigenen Server

## Tech-Stack

React 19 · Vite · Tailwind CSS · OpenLigaDB REST-API

## Lokal starten

```bash
npm install
npm run dev
```

Gebaut wird mit `npm run build` (Ausgabe in `dist/`), auf Vercel ohne weitere Konfiguration.
